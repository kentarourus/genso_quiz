# 元素クイズ

原子番号・元素記号・元素名を組み合わせて練習できる、ブラウザで動く元素クイズアプリです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 「問題」と「回答」から、出題形式を選びます。
   - 原子番号
   - 元素記号
   - 元素名
3. セット数を選びます。
   - 5問
   - 10問
   - 20問
   - 50問
4. 「セット開始」を押して回答します。
5. セットが終わると、正解数と所要時間が「セット記録」に残ります。

## 主な機能

- 118元素すべてからランダム出題
- 原子番号・元素記号・元素名の相互クイズ
- セット単位での学習
- セット完了までの時間計測
- セット記録の保存
- 最近の問題履歴
- ヒント表示
- 成績リセット
- スマホ幅に対応した表示

## 記録について

セット記録はブラウザの `localStorage` に保存されます。同じブラウザで開くと前回の記録が残ります。

記録を消したい場合は、アプリ内の「消去」ボタンを押してください。

## 開発メモ

外部ライブラリは使っていません。HTML、CSS、JavaScriptだけで動きます。
